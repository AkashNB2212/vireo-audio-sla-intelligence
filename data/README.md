# Task pack goes here (not committed)

The original task pack is **confidential** and intentionally excluded from this repository. It contains customer and employee personal data and client-internal documents.

To run the project, copy these two files from the task pack supplied with the assignment into this folder:

- `tickets.csv`
- `agents.csv`

The other pack files (customer, order and product data and the other supporting documents) are not read by the code. Everything in this folder except this README is ignored by git.
